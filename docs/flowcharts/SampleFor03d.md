# SampleFor03d — フローチャートとトレース表

- 対象ファイル: `src/vol06_02/SampleFor03d.java`
- パッケージ: `vol06_02`
- テーマ: for の初期化部・更新式でカンマ演算子を使って複数の変数を扱う。

## ソースの要点

```java
int i, j;
for (i = 0, j = 0; i <= 5; i++, j++) {
    System.out.println(i + j);
}
```

## フローチャート

```mermaid
flowchart TD
    A([開始]) --> B["i = 0, j = 0"]
    B --> C{"i <= 5 ?"}
    C -- Yes --> D["print i + j"]
    D --> E["i++, j++"]
    E --> C
    C -- No --> F([終了])
```

## 学習ポイント

- for の初期化部・更新式は、カンマ区切りで複数並べられる。
- ただし条件式は 1 つだけ（`&&` や `||` で組み合わせる）。
- 二つの変数を同期して動かしたいときに便利。
