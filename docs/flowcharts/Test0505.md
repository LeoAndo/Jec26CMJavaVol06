# Test0505 — フローチャートとトレース表

- 対象ファイル: `src/Test0505.java`
- パッケージ: デフォルト
- テーマ: `{}` を省略した if 文の動作確認。

## ソースの要点

```java
int x = 1;
if (x < 10)
    System.out.print("A");
System.out.print("B");
```

## フローチャート

```mermaid
flowchart TD
    A([開始]) --> B["x = 1"]
    B --> C{"x < 10 ?"}
    C -- "true" --> D["A を出力"]
    C -- "false" --> E["B を出力"]
    D --> E
    E --> Z([終了])
```

## トレース表

| ステップ | 文 | x | 条件判定 | 出力 |
|---|---|---|---|---|
| 1 | `int x = 1` | 1 | - | - |
| 2 | `if (x < 10)` | 1 | `1 < 10` → true | - |
| 3 | `System.out.print("A")` | 1 | - | A |
| 4 | `System.out.print("B")` | 1 | - | B |

## 実行結果（標準出力）

```
AB
```

## 学習ポイント

- `{}` を省略した if 文は、直後の 1 文だけが本体。
- `System.out.print("B")` は if と無関係に常に実行される。
- 出力が改行されないので `AB` と連結される。
