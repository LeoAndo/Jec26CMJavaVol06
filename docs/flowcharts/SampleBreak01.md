# SampleBreak01 — フローチャートとトレース表

- 対象ファイル: `src/vol06_02/SampleBreak01.java`
- パッケージ: `vol06_02`
- テーマ: 無限 while ループ内で `break` を使って抜ける。

## ソースの要点

```java
int i = 0;
while (true) {
    if (i > 2) {
        break;       // ループを抜ける
    }
    System.out.println(i);
    i++;
}
```

## フローチャート

```mermaid
flowchart TD
    A([開始]) --> B["i = 0"]
    B --> C{"true ?"}
    C -- Yes --> D{"i > 2 ?"}
    D -- Yes --> H([終了 (break)])
    D -- No --> E["print i"]
    E --> F["i++"]
    F --> C
```

## トレース表

| ステップ | 文 | 実行前 i | 条件 i>2 | 実行後 i | 出力 | コメント |
|----|----|----|----|----|----|----|
| 1 | `int i = 0;` | - | - | 0 | （なし） | |
| 2 | `while(true)` | 0 | - | 0 | （なし） | 条件 true |
| 3 | `if (i > 2)` | 0 | false | 0 | （なし） | break しない |
| 4 | `println(i)` | 0 | - | 0 | `0` | |
| 5 | `i++` | 0 | - | 1 | （なし） | |
| 6 | `if (i > 2)` | 1 | false | 1 | （なし） | break しない |
| 7 | `println(i)` | 1 | - | 1 | `1` | |
| 8 | `i++` | 1 | - | 2 | （なし） | |
| 9 | `if (i > 2)` | 2 | false | 2 | （なし） | break しない |
| 10 | `println(i)` | 2 | - | 2 | `2` | |
| 11 | `i++` | 2 | - | 3 | （なし） | |
| 12 | `if (i > 2)` | 3 | true | 3 | （なし） | **break で抜ける** |

## 実行結果（標準出力）

```
0
1
2
```

## 学習ポイント

- `break` は最も内側のループを即座に抜ける。
- `while (true)` のような無限ループは、内部の `break` が事実上の終了条件になる。
- `i > 2` の判定タイミングによっては、想定より 1 回多い／少ない出力になることがある点に注意。
