# SampleFor03c — フローチャートとトレース表

- 対象ファイル: `src/vol06_02/SampleFor03c.java`
- パッケージ: `vol06_02`
- テーマ: for の初期化部を省略する書き方。

## ソースの要点

```java
int i = 1;
for (; i <= 5; i++) {   // 初期化部を省略
    System.out.println(i + "回目");
}
```

## フローチャート

```mermaid
flowchart TD
    A([開始]) --> B["int i = 1（事前に初期化）"]
    B --> C{"i <= 5 ?"}
    C -- Yes --> D["print i + 回目"]
    D --> E["i++"]
    E --> C
    C -- No --> F([終了])
```

## 学習ポイント

- for の初期化部は省略可能（`;` は残す）。
- 省略する場合、変数は for の前で初期化しておく必要がある。
- 初期化を外に出すことで、別の処理を挟むことができる。
