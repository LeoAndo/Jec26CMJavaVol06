Test0513 — フローチャートとトレース表

  • 対象ファイル: src/Test0513.java
  • パッケージ: デフォルト
  • テーマ: 代入式が値を返すことを利用したトリッキーな if 文。b = !b の中で代入と評価を同時に行う。

ソースの要点

int x = 10;
boolean b = false;
if (b = !b) {
    System.out.print(x = 2 * x);
} else {
    System.out.print(b);
}

フローチャート

flowchart TD
    A([開始]) --> B["x = 10, b = false"]
    B --> C["!b を評価 → true"]
    C --> D["b = true (代入式の値も true)"]
    D --> E{"if (true) ?"}
    E -- "true" --> F["x = 2*x → x=20、x を出力"]
    E -- "false" --> G["b を出力"]
    F --> Z([終了])
    G --> Z

トレース表

ステップ文xb条件判定出力
1int x = 1010---
2boolean b = false10false--
3if (b = !b)10true代入式の値 true → if 成立-
4x = 2 * x20true--
5System.out.print(x)20true-20

実行結果（標準出力）

20

学習ポイント

  • b = !b は代入式。値は代入後の b（true）を返す。
  • ==（比較）と =（代入）の取り違えに注意。boolean 型では = でも文法的に通ってしまう。
  • x = 2 * x も代入式で、println の引数として代入後の値（20）が出力される。
