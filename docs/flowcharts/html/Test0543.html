Test0543 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/Test0543.java
  • パッケージ: vol06_02
  • テーマ: 更新式に i += 3 を使い、3 飛ばしで増加する for 文。

ソースの要点

for (int i = 1; i <= 10; i += 3) {
    System.out.print(i + " ");
}
  • i は 1, 4, 7, 10, 13 ... と 3 ずつ増える。

フローチャート

flowchart TD
    A([開始]) --> B["i = 1"]
    B --> C{"i <= 10 ?"}
    C -- true --> D["print i + ' '"]
    D --> E["i += 3"]
    E --> C
    C -- false --> F([終了])

トレース表

周回判定式結果出力i += 3 後
11 <= 10true1 4
24 <= 10true4 7
37 <= 10true7 10
410 <= 10true10 13
513 <= 10false--

実行結果（標準出力）

1 4 7 10

学習ポイント

  • 等差の差分（公差）は更新式で調整できる。
  • 終了条件が <= 10 なので、10 はちょうど含まれる点に注意。
