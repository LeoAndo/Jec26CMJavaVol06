SampleFor01 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/SampleFor01.java
  • パッケージ: vol06_02
  • テーマ: for 文の基本構文（初期化・条件・更新式）。

ソースの要点

int i;
for (i = 1; i <= 5; i++) {
    System.out.println(i + "回目");
}

フローチャート

flowchart TD
    A([開始]) --> B["i = 1（初期化）"]
    B --> C{"i <= 5 ?"}
    C -- Yes --> D["print i + 回目"]
    D --> E["i++（更新）"]
    E --> C
    C -- No --> F([終了])

学習ポイント

  • for 文は「初期化 → 条件 → 本体 → 更新 → 条件 → ...」と動く。
  • 変数 i は for 文の外で宣言しているので、ループ後も使える。
  • while 文に比べて「回数を決めた繰り返し」を簡潔に書ける。
