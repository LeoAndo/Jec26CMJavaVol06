Test0514 — フローチャートとトレース表

  • 対象ファイル: src/Test0514.java
  • パッケージ: デフォルト
  • テーマ: 三項演算子で boolean を返すサンプル。

ソースの要点

int a = 3;
int b = 9;
boolean c = (a < b ? false : true);
System.out.println(c);

フローチャート

flowchart TD
    A([開始]) --> B["a = 3, b = 9"]
    B --> C{"a < b ?"}
    C -- "true" --> D["c = false"]
    C -- "false" --> E["c = true"]
    D --> F["c を出力"]
    E --> F
    F --> Z([終了])

トレース表

ステップ文abc条件判定出力
1int a = 33----
2int b = 939---
3boolean c = (a < b ? false : true)39false3 < 9 → true → false を選ぶ-
4System.out.println(c)39false-false

実行結果（標準出力）

false

学習ポイント

  • 三項演算子は boolean を返すことも可能。
  • a < b ? false : true は意味的には !(a < b) と同じ。冗長な書き方の代表例。
  • このような書き方を見たら、より簡潔な ! で書き直せないか検討する。
