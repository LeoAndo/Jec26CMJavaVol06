Test0542 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/Test0542.java
  • パッケージ: vol06_02
  • テーマ: 更新式に乗算 i *= 2 を使った for 文。i は 1, 2, 4, 8 と倍々になる。

ソースの要点

for (int i = 1; i <= 10; i *= 2) {
    System.out.print(i + " ");
}
  • 更新式は必ずしも i++ でなくてよい。
  • i *= 2 で「i を 2 倍する」更新。

フローチャート

flowchart TD
    A([開始]) --> B["i = 1"]
    B --> C{"i <= 10 ?"}
    C -- true --> D["print i + ' '"]
    D --> E["i *= 2"]
    E --> C
    C -- false --> F([終了])

トレース表

周回判定式結果出力i *= 2 後

実行結果（標準出力）

1 2 4 8

学習ポイント

  • 更新式は任意の式が書けるので、等差だけでなく等比（倍々）も可能。
  • 2 のべき乗を順に出すパターンで使われる。
