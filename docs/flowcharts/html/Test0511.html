Test0511 — フローチャートとトレース表

  • 対象ファイル: src/Test0511.java
  • パッケージ: デフォルト
  • テーマ: 短絡演算子 && の動作。左辺が false なら右辺は評価されず、副作用も発生しない。

ソースの要点

int x = 2, y = 3;
if (x++ == 0 && y++ >= 3) {
    System.out.print("A");
} else {
    System.out.print("B");
}
System.out.print(":" + x + ":" + y);

フローチャート

flowchart TD
    A([開始]) --> B["x = 2, y = 3"]
    B --> C["左辺 x++==0 評価: x=2 を使い、x=3 に。結果 false"]
    C --> D{"左辺が false なので && は false 確定"}
    D --> E["右辺は評価しない (y はそのまま)"]
    E --> F["B を出力"]
    F --> G[":x:y を出力"]
    G --> Z([終了])

トレース表

ステップ文xy条件判定出力
1int x = 2, y = 323--
2x++ == 0 を評価2 → 332 == 0 → false-
3&& 短絡33左辺 false → 右辺評価せず-
4else 実行 → System.out.print("B")33-B
5System.out.print(":" + x + ":" + y)33-:3:3

実行結果（標準出力）

B:3:3

学習ポイント

  • && は 短絡評価。左辺で結果が確定すれば右辺は評価されない。
  • 右辺の y++ が実行されないので y は 3 のまま。
  • Test0510（&）との違いを比較して、副作用と短絡の関係を理解する。
