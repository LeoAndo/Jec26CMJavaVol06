Test0533 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/Test0533.java
  • パッケージ: vol06_02
  • テーマ: while で 1〜3 の合計を求める累積加算 (1 + 2 + 3 = 6)。

ソースの要点

int i = 0, j = 0;
while (i < 3) {
    i++;
    j = j + i;
}
System.out.print(j);
  • i をカウンタとして 1, 2, 3 と進めながら、j に加算する。
  • ループ終了後に j（合計）を 1 回だけ表示する。

フローチャート

flowchart TD
    A([開始]) --> B["i = 0, j = 0"]
    B --> C{"i < 3 ?"}
    C -- true --> D["i++"]
    D --> E["j = j + i"]
    E --> C
    C -- false --> F["print j"]
    F --> G([終了])

トレース表

周回判定式結果i++ 後 ij = j + i 後 j
10 < 3true10 + 1 = 1
21 < 3true21 + 2 = 3
32 < 3true33 + 3 = 6
43 < 3false--

ループ終了後: print(j) → 6

実行結果（標準出力）

6

学習ポイント

  • 累積加算は「カウンタ i」と「合計 j」を分けて管理する典型パターン。
  • 出力をループ内に置くか外に置くかで結果が大きく変わる。
