SampleFor03a — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/SampleFor03a.java
  • パッケージ: vol06_02
  • テーマ: for 文の初期化部で変数を宣言する基本形。

ソースの要点

for (int i = 1; i <= 5; i++) {
    System.out.println(i + "回目");
}

フローチャート

flowchart TD
    A([開始]) --> B["int i = 1"]
    B --> C{"i <= 5 ?"}
    C -- Yes --> D["print i + 回目"]
    D --> E["i++"]
    E --> C
    C -- No --> F([終了])

学習ポイント

  • for の初期化部で int i = 1 のように宣言できる（最もよく使う形）。
  • この場合 i は for ブロックの中だけで有効（ブロックスコープ）。
  • SampleFor01 と違って、ループの外で i を使うことはできない。
