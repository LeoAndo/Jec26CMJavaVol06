SampleBreak01 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/SampleBreak01.java
  • パッケージ: vol06_02
  • テーマ: 無限 while ループ内で break を使って抜ける。

ソースの要点

int i = 0;
while (true) {
    if (i > 2) {
        break;       // ループを抜ける
    }
    System.out.println(i);
    i++;
}

フローチャート

flowchart TD
    A([開始]) --> B["i = 0"]
    B --> C{"true ?"}
    C -- Yes --> D{"i > 2 ?"}
    D -- Yes --> H(["終了 (break)"])
    D -- No --> E["print i"]
    E --> F["i++"]
    F --> C

トレース表

実行結果（標準出力）

0
1
2

学習ポイント

  • break は最も内側のループを即座に抜ける。
  • while (true) のような無限ループは、内部の break が事実上の終了条件になる。
  • i > 2 の判定タイミングによっては、想定より 1 回多い／少ない出力になることがある点に注意。
