Test0558 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/Test0558.java
  • パッケージ: vol06_02
  • テーマ: for 文での continue（次の反復へスキップ）。

ソースの要点

for (int i = 0; i < 5; i++) {
    if (i % 3 == 1)
        continue;
    System.out.print(i + " ");
}

フローチャート

flowchart TD
    A([開始]) --> B["i = 0"]
    B --> C{"i < 5 ?"}
    C -- No --> Z([終了])
    C -- Yes --> D{"i % 3 == 1 ?"}
    D -- Yes --> F["continue → i++"]
    D -- No --> E["print i + ' '"]
    E --> F
    F --> C

トレース表

反復ii<5?i%3==1?動作出力

21truetruecontinue-
32truefalseprint2

54truetruecontinue-

実行結果（標準出力）

0 2 3

学習ポイント

  • continue は当該反復だけスキップし、更新部（i++）→ 条件判定に飛ぶ。
  • i % 3 == 1 を満たす i=1, 4 がスキップされる。
  • 残った 0, 2, 3 のみ出力される。
