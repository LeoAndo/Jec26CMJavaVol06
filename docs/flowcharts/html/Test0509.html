Test0509 — フローチャートとトレース表

  • 対象ファイル: src/Test0509.java
  • パッケージ: デフォルト
  • テーマ: 排他的論理和 ^ と論理 NOT ! の組み合わせを学ぶ。

ソースの要点

boolean b1 = true;
boolean b2 = b1;
if (b1 ^ !b2) {
    System.out.print("A");
} else {
    System.out.print("B");
}

フローチャート

flowchart TD
    A([開始]) --> B["b1 = true"]
    B --> C["b2 = b1 (=true)"]
    C --> D["!b2 を評価 → false"]
    D --> E{"b1 ^ !b2 = true ^ false ?"}
    E -- "true" --> F["A を出力"]
    E -- "false" --> G["B を出力"]
    F --> Z([終了])
    G --> Z

A

学習ポイント

  • ^ は排他的論理和（XOR）。2 つが異なるとき true。
  • true ^ false は true、true ^ true や false ^ false は false。
  • ! で boolean を反転できる。
