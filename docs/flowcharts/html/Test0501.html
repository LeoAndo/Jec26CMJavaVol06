Test0501 — フローチャートとトレース表

  • 対象ファイル: src/Test0501.java
  • パッケージ: デフォルト
  • テーマ: 基本の if 文の動作確認。条件 true のときの分岐 + 後続の文の実行。

ソースの要点

int x = 10;
if (x > 5) {
    System.out.print("A");
}
System.out.print("B");

フローチャート

flowchart TD
    A([開始]) --> B["x = 10"]
    B --> C{"x > 5 ?"}
    C -- "true" --> D["A を出力"]
    C -- "false" --> E["B を出力"]
    D --> E
    E --> Z([終了])

トレース表

ステップ文x条件判定出力
1int x = 1010--
2if (x > 5)1010 > 5 → true-
3System.out.print("A")10-A
4System.out.print("B")10-B

実行結果（標準出力）

AB

学習ポイント

  • print は改行しないので、A と B が連結される。
  • if のブロック外にある文は条件と無関係に常に実行される。
