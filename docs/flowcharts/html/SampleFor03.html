SampleFor03 — フローチャートとトレース表

  • 対象ファイル: src/vol06_02/SampleFor03.java
  • パッケージ: vol06_02
  • テーマ: for 文の二重ループ。

ソースの要点

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 5; j++) {
        System.out.println(i + ":" + j);
    }
}

フローチャート

flowchart TD
    A([開始]) --> B["i = 1"]
    B --> C{"i <= 3 ?"}
    C -- Yes --> D["j = 1"]
    D --> E{"j <= 5 ?"}
    E -- Yes --> F["print i + : + j"]
    F --> G["j++"]
    G --> E
    E -- No --> H["i++"]
    H --> C
    C -- No --> I([終了])

学習ポイント

  • 二重ループでは、外側 1 回ごとに内側を最後まで実行する。
  • 合計の実行回数は外側 × 内側 = 3 × 5 = 15 回。
  • 変数 i, j は for 文の中で宣言しているのでループ後は使えない。
