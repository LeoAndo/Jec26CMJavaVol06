# Test0534 — フローチャートとトレース表

- 対象ファイル: `src/vol06_02/Test0534.java`
- パッケージ: `vol06_02`
- テーマ: while と if を組み合わせ、0〜10 の偶数だけを出力する。

## ソースの要点

```java
int i = 0;
while (i <= 10) {
    if (i % 2 == 0)
        System.out.print(i + " ");
    i++;
}
```

- 0 から 10 までのすべての値を順に判定し、偶数のときだけ出力する。

## フローチャート

```mermaid
flowchart TD
    A([開始]) --> B["i = 0"]
    B --> C{"i <= 10 ?"}
    C -- true --> D{"i % 2 == 0 ?"}
    D -- true --> E["print i + ' '"]
    D -- false --> F["i++"]
    E --> F
    F --> C
    C -- false --> G([終了])
```

| 2 | 1 | true | false | （なし） | 2 |

## 実行結果（標準出力）

```
0 2 4 6 8 10 
```

## 学習ポイント

- ループ内に if を組み合わせることで「条件を満たすものだけ処理する」典型パターンになる。
- `i % 2 == 0` は偶数判定。奇数は `i % 2 != 0` や `i % 2 == 1`。
- 0 も偶数として扱われる。
