# Test0539 — フローチャートとトレース表

- 対象ファイル: `src/vol06_02/Test0539.java`
- パッケージ: `vol06_02`
- テーマ: do-while で 2 つの変数 a, b が連動して変化する累積処理。

## ソースの要点

```java
byte a = 1;
byte b = 0;
do {
    b++;
    a = a + b;
    System.out.print("*");
} while (a < 5);
```

- 各周回で b を +1 し、a に b を足し込む。
- a が 5 以上になったらループ終了。

## コンパイルエラーについて

このソースは、`a = a + b;` の行でコンパイルエラーになります。

`a + b` では、Java の **算術昇格（arithmetic promotion）** が発生します。`byte` 同士の加算でも、Java は自動的に両方を `int` に変換してから計算します。そのため、計算結果は `int` 型になり、`byte` 型の変数 `a` にそのまま代入することはできません。

一方、`b++` は `++` 演算子が暗黙的にキャストを行うため、`byte` 型の変数に対してもコンパイルエラーにはなりません。

## フローチャート

```mermaid
flowchart TD
    A([開始]) --> B["a = 1, b = 0"]
    B --> C["b++"]
    C --> D["a = a + b"]
    D --> E["print *"]
    E --> F{"a < 5 ?"}
    F -- true --> C
    F -- false --> G([終了])
```

## トレース表

| 周回 | b++ 後 b | a = a + b 後 a | 出力 | 判定式 | 結果 |
|----|----|----|----|----|----|
| 1 | 1 | 1 + 1 = 2 | `*` | `2 < 5` | true |
| 2 | 2 | 2 + 2 = 4 | `**` | `4 < 5` | true |
| 3 | 3 | 4 + 3 = 7 | `***` | `7 < 5` | false |

## 実行結果（標準出力）

```
***
```

## 学習ポイント

- 2 変数を連動させると、増分が単純な等差ではなく階段状になる（+1, +2, +3 …）。
- do-while は条件判定が後ろなので、最後の 1 回は条件を満たさない値で実行される。
- `byte` 型でも加算結果は `int` 型に昇格するため、`byte = byte + byte` の形ではコンパイルエラーになる。
- `b++` のようなインクリメント演算子では、演算後の値が暗黙的に元の型へ戻される。
